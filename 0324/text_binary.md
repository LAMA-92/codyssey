# 텍스트 파일과 이진 파일의 차이점 및 장단점

## 1. 차이점

- **핵심 차이점:** 누가 읽을 수 있는가 
- **텍스트 파일:** **사람**이 이해 할 수 있는 **문자**(ASCII, UTF-8)로 작성 되어 있음
- **이진 파일:** **컴퓨터**가 이해 할 수 있는 **이진수**로 작성 되어 있음


## 2. 장단점

## 2-1. 텍스트 파일
- **장점:**
- 1. 가독성 : 누구나 읽을 수 있음
  2. 호환성 : 모든 운영체제와 언어에서 쉽게 공유됨
  3. 유지보수 용이 : 에러 발생 시 데이터 오염을 쉽게 확인 할 수 있음
- **단점:**
- 1. 속도 : 숫자를 문자로 변환하는 과정에서 부하 발생
  2. 용량 : 숫자가 커질수록 차지하는 바이트 수가 늘어남
 
## 2-2. 이진 파일
- **장점:**
- 1. 효율성 : 파일 용량이 작아 읽기/쓰기 속도가 빠름
  2. 정밀도 : 숫자 데이터를 변환 없이 그대로 보존 가능 
- **단점:**
- 1. 가독성 : 전용 프로그램이나 코드 없이 사람이 확인 불가
  2. 취약성 : 1비트 만 깨져도 파일 전체 손상 위험 존재
